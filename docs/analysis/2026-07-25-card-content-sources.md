## Scope of this batch

The 25 open/globular clusters in `celestial-clusters.js` whose `"f"` field carried the

## Method

Per the plan's workflow: draft grounded in official/refereed sources → record sources here →
owner approves → land. Numerical facts (distance, age, apparent magnitude) were **not
re-derived** — they were already hand-verified in each record's `"st"` field per this file's own
header ("hand-verified against modern literature after an Astra realism review," 2026-07-20).
This batch supplies only the `"f"` (field note) and `"lo"` (one sourced fact) text, using the
existing `"st"` numbers as the factual anchor. Every `"lo"` entry traces to a search performed
this session (WebSearch, session-logged) against a primary or authoritative secondary source —
no fact below was drafted from memory alone without a corresponding search to confirm it.
