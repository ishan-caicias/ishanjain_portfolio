## Numbers appendix

- **Obliquity check:** `cos(23.439281°) = 0.9174821`, `sin(23.439281°) = 0.3977772` — matches
  the brief's own pinned values (`references/planetary-science.md`) to 7 decimal places, and the
  shipped unit test (`asteroid-dr3-belt.test.ts`, "applies the real J2000 obliquity") already
  asserted this before D6.2; the runtime copy now matches it too (new cross-module test).
- **Aldebaran ecliptic latitude (order-of-magnitude, from Astra's independent conversion):**
  converting ra 68.980°/dec 16.509° to ecliptic coordinates gives an ecliptic latitude β ≈ +5.4°
  — well inside the ~±10-15° band real main-belt asteroid inclinations (this catalog's own
  physics cut: `i < 5°` for the _orbits_, but the _belt's angular width as seen from the origin_
  at ~2.7 AU / ~1 ly viewing geometry is generously wide near opposition) sweep through at this
  scene's exaggerated (declared) angular scale. Consistent with the measured peak density ≈0.96
  (near-total tube coverage) rather than a grazing hit.
- **m42 ecliptic latitude:** ra 83.822°/dec −5.391° converts to β ≈ −18.9° — well outside the
  belt's populated latitude range, consistent with the measured peak density collapsing to
  ≈0.0001 (residual only from the belt's own `radialSpread`/`densitySigmaVertical` Gaussian
  tails, not a real crossing).
- **Kirkwood invariance, directly observed:** the regenerated console report (`node
scripts/gaia-asteroids-pngpack.mjs --frame equatorial`) still shows depleted bins at all four
  resonances (3:1, 5:2, 7:3, 2:1) relative to their neighbours — this is measured from the
  ACTUAL post-rotation run, not asserted from the pre-existing (frame-invariant) unit tests
  alone, and it is the same real structure Astra's PF-10 C3 brief originally certified.
