## What this slice is

D2.1/D2.2 (TR-090) gated the belt/furniture and collapsed the whole local galaxy at extragalactic
arrivals, but left one honesty gap the D2 realism review's own "does not cover" section named: the
constellation figures rode along under D2.2's `_localFieldFade` (they only went to 0 at ≥1e6 ly)
even though they are, per Astra §1, "parallax accidents of nearby stars" that stop being honest at
destinations two to three orders of magnitude nearer than an extragalactic arrival. D2.3 gives the
figures their own, nearer dissolve — `ly 50→500` — and completes the license ledger the science
brief proposed at PF-11's start.

## What shipped

**New scheduler (`ship-dynamics.ts`):** `FIGURE_FADE_START_LY = 50`, `FIGURE_GONE_LY = 500`,
`figureVisibility(ly) = 1 - smoothstep(50, 500, ly)` — same shape as D2.1's `furnitureVisibility`,
a separate, nearer window than D2.2's binary `localFieldVisibility` (1e6 ly).

**Engine (`babylon-engine.ts`):** new `_figureFade`/`_figureFadeFrom`/`_figureFadeTo` fields,
captured per journey in `_beginWarp` (`_figureFadeTo = figureVisibility(lyTotal)`) and scheduled
each frame in `_updateFrameLadder` through the same `frameLadderFade(from, to, k, reduced)`
front-loaded-out/back-loaded-in warp curve D2.1/D2.2 already use. **No new shader uniform was
needed** — the constellation figures have no shader-level fade term; their alpha is already driven
CPU-side in `_pushAberration` (`_conMat.setColor4("uColor", ...)`), so D2.3 adds one more
multiplicand to the existing expression:

```
this._conColorScratch.a = 0.34 * (1 - beta) * this._localFieldFade * this._figureFade;
```

`sceneStats().figureFade` exposes the live value (rounded to 3 decimals, matching `furnitureFade`/
`localFieldFade`'s convention).

**License ledger — completed as a dated addendum on the science brief**, per the implementation
plan's "4 from the brief + Reinhard ratio compression" instruction: **L14** belt overbrightness
(~10⁶×, formalised — already implemented by D2.1), **L15** seconds-scale warp durations
(~1.2×10⁵×–1.2×10⁸×, distance-dependent — derived from `warpDurationForLy` against the brief's
brachistochrone honesty table), **L16** band + star field persistence during in-galaxy travel
(≤~2°/kly — narrowed by this slice to exclude the figures, which now have their own L17), **L17**
(NEW) the `ly 50→500` dissolve window itself, graded DECLARED LICENSE by Astra rather than
ACCURATE — real constellation-figure stars span roughly 80 to 2,600 ly, so no single scene-wide
constant is exactly right per-figure. Two of the five ledger items the implementation plan named
were already ledgered at their point of origin and are cross-referenced rather than duplicated:
**L9** (intro timing compression, D1.3) and **L1** (Reinhard compression, D6.1).

## Non-negotiables honoured

- **#18 behaviour, not readiness:** the E2E drives real `travelTo` to Mars/Polaris/M42/nbg/home and
  reads `sceneStats().figureFade`, not an engine-internal call.
- **#24 reduced motion:** `figureFade` is scheduled through the same `frameLadderFade` reduced-motion
  branch as D2.1/D2.2 — holds `from` until arrival, then jumps to `to`; no animated dissolve frame is
  ever rendered under reduced motion.
- **#15 no test weakened:** every change to `frame-ladder.spec.ts`/`frame-ladder.test.ts` is
  additive — new assertions and a new travel leg (Polaris); no existing assertion's expected value
  or timeout was loosened.
- **Docs contract:** the license ledger (a science-brief addendum + the realism-review audit) landed
  in the same turn as the code, per the delivery plan's `-> analysis doc` exit criterion.

## Astra REALISM-AUDIT

[docs/analysis/2026-07-23-pf11-d2-frame-ladder-realism-review.md, D2.3 section](../analysis/2026-07-23-pf11-d2-frame-ladder-realism-review.md#realism-audit--d23-constellation-dissolve-2026-07-23-astra).
The split-schedule mechanism (figures fade separately from, and nearer than, the extragalactic
collapse) is graded **ACCURATE**; the Mars/Polaris/M42 checkpoints are **ACCURATE given the
license**; the `ly 50→500` window itself is graded **DECLARED LICENSE (L17)** — real
constellation-figure stars span ~80 ly (Merak) to ~2,600 ly (Deneb), so a single scene-wide
constant necessarily over- or under-shoots any individual figure's true parallax-breakdown
distance. The audit's numbers appendix computes the small-angle parallax (`Δθ ≈ x/d`) for a near
figure (Ursa Major, ~80-125 ly members: ~36° distortion already at the fade-start threshold) and a
far one (Orion, ~1,260-2,000 ly members: ~23° at the fade-gone threshold), concluding the window
errs toward removing figures rather than lingering with them visibly wrong — the honest trade for
one CPU-side alpha term standing in for 88 different true depths.

## Known limitations / follow-ups

- **The `ly 50→500` window is a scene-wide constant, not per-figure.** Recorded as L17, not a
  defect — a per-figure depth-aware version is a legitimate future refinement if the figures ever
  become more than background decoration, per the audit's recommendation.
- **Manual regression could not drive a warp to arrival** (backgrounded-tab throttle, same as every
  travel-cinematic slice since D6.4) — behavioural proof is the Playwright E2E path, not the MCP
  Browser pane, for any slice involving `travelTo`.
- Phase D2 (frame ladder) is now **complete** — D2.1 furniture gating, D2.2 extragalactic collapse,
  D2.3 constellation dissolve + ledger. Phase D3 (flight model v4) is next per the delivery plan.

## REVIEW addendum (2026-07-24, same day, post-gate — Fable 5)

A fresh-eyes adversarial review of this slice (model switched, same arrangement as TR-090's) found
**one comment-honesty defect and no code defects**: the `FIGURE_FADE_START_LY` doc comment claimed
"50 ly is well past every star the figures are drawn from" — factually backwards (figure stars span
~43 ly Capella to ~2,600 ly Deneb; 50 ly is past almost none of them), and directly contradicted by
Astra's own L17 audit in the same slice. The threshold is correct; the stated justification was
wrong. Rewritten to the audit's actual rationale (nearest figures already parallax-shifted by tens
of degrees at 50 ly of displacement; a declared scene-wide window per L17, not a derived
threshold). Comment-only change — re-verified with lint + the frame-ladder unit file (20/20).

**Checked and cleared:** the Polaris assertion is not vacuous (`figureVisibility(433)` ≈ 0.06,
strictly inside (0,1) after the stats rounding); the one-frame lag between `_updateFrameLadder`
and `_pushAberration`'s read is the identical pre-existing D2.2 pattern (`_localFieldFade`), exact
at settled states; all warp entry paths (goHome, ascent, mid-warp retarget) capture the fade
endpoints correctly; no other writer touches `_conMat`'s `uColor`; no test assertion weakened.
`npm run docs:check` green. The untracked `dev/null/*` directory in the working tree was
identified as Git-LFS hook stubs written to a literal `dev/null` path (Windows hookspath
mangling) — excluded from the slice commit, flagged to the owner for deletion.
