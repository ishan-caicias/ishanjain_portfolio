## Suite determinism (the TR-018 lineage, closed)

With five GPU-heavy spec files time-slicing ONE SwiftShader emulator, local parallel workers
were fictional: 4 workers → rotating 1–3 failures/run; 2 workers → still 1/run; every instance
passed in isolation (documented across TR-018/043–051). **Local workers are now 1** (CI already
was): two consecutive full-suite runs passed 70/70. Cost ~2–3 min/run; worth determinism and
exact CI parity. The interim per-file serialization (TR-047) remains harmlessly in place.

  (hash-named chunks make name attribution unreliable — the largest-chunk gate covers the
