## What Was Delivered

1. **Engine fork under lint** — `space-engine.js` left the ignore lists, one-time formatted
   (1,469 → 2,302 lines), two dead-code lint errors fixed. Suite proved no behaviour change.
2. **`src/lib/craft-loader.ts`** — purpose-built GLB parser/renderer split for testability:
   `parseCraftGlb()` (pure: container parse, meshopt decode, quantized-attribute extraction,
   node-transform composition, unit-box model matrix) + `CraftShip` (GL upload, WebP textures
   via `createImageBitmap`, PBR-lite shader: baseColor × AO, normal mapping via tangents,
   fixed key light, rim, emissive boost, filmic-ish rolloff).
3. **Engine wiring** — `craft` attribute (`off` default → wireframe untouched), depth-enabled
   context (test enabled only in the craft pass), identical `_drawShip` placement chain for
   both paths, glow points on both paths, error → wireframe fallback, context-restore
   re-upload/retry, `data-craft-state` + `cosmos:craft` observability.
4. **Flag plumbing** — `?craft=1k|2k` in `SpaceScene.tsx`.
5. **CSP** — `script-src` gains `'wasm-unsafe-eval'` (see ADR 0002, Decision 3).
6. **Tests** — +5 unit (parser vs real committed GLBs, incl. an independent re-verification of
   the unit-box model matrix), +3 E2E (both tiers reach `ready` with no page/console errors;
   flag-off never engages the craft path). All LFS-pointer-aware.

## Defects Found and Fixed During VERIFY (real E2E catches)

| Defect                                                                                                                                                               | Found by                                | Fix                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- | ----------------------------------------------------------- |
| CSP blocked the meshopt WASM compile (`craft-state: error`, wireframe kept)                                                                                          | Craft E2E + browser console             | `'wasm-unsafe-eval'` in `script-src` (ADR 0002)             |
| `const vec3 L = normalize(...)` — illegal non-constant global const in GLSL ES 1.0; real GPU drivers lenient, ANGLE/SwiftShader (headless, CI-like) correctly reject | Craft E2E under headless chromium       | Pre-normalized literal                                      |
| Context-loss during craft load latched `error` forever                                                                                                               | Headless console (`CONTEXT_LOST_WEBGL`) | `_rebuildGL` retries `_loadCraft()` when craft is absent    |
| Hull rendered near-silhouette (fade misapplied as raw exposure in the opaque pass)                                                                                   | Quality-gate screenshot                 | fade → `sqrt(fade)` presence curve + lighting/emissive tune |

The engine's designed fallback (**any craft failure → wireframe, never a blank ship**) was
proven organically by the first two defects.
