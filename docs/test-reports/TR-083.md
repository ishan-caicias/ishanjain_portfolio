## The anomaly — reversed this round, cause still unconfirmed

TR-068/069 established a reproducible pattern across two independent sessions: the 2024 flagship
(S24 Ultra) scored **below** the 2020 mid-tier phone (S20 FE) on render fps — 28–37 fps vs 42–49
fps — backwards from what the hardware classes would predict.

**This round inverts it:** S24 Ultra 60 fps vs S20 FE 45 fps — the expected ordering, and the
flagship's best reading across all three rounds by a wide margin (60 vs its own prior 28–37).
S20 FE stayed in its established band (45 fps, within its 42–49 fps range across all three
rounds) — consistent behaviour on that device makes the S24 Ultra's jump the real story, not
noise on both sides.

**Why this can't be conclusively attributed yet:** no code in this session (D0.1/D0.2) touched
`adaptToDeviceRatio`, DPR capping, or tier-resolution logic — nothing was _fixed_. Plausible,
unconfirmed explanations, in the same spirit as TR-068's original list:

- **Tier resolution differs this round.** PF-10's C3/C4 (asteroid belt, planet spheres) landed
  between TR-069 and now, changing `craft-tier.ts`'s input signals' effective load. If the S24
  Ultra now resolves to a lower tier than the prior two rounds, fewer objects render — a real,
  independent variable the missing `TIER` line would settle immediately.
- **Backend divergence**, same standing hypothesis: if this reading landed on WebGL2 (not
  WebGPU) this time, it isn't measuring the same path as rounds 1–2 claimed to.
- **Device/session state**: thermal history, background load, and Chrome version drift between
  2026-07-20 and 2026-07-22 are real and uncontrolled variables on a personal phone.
- **Low battery (8%/6%) is not a sufficient explanation on its own** — Samsung One UI's automatic
  power-saving typically engages well above these levels, which would be expected to suppress
  performance, not improve it. The S24 Ultra improving despite critically low battery argues
  _against_ battery state being the dominant driver here, though it cannot be ruled out for the
  S20 FE (whose reading stayed flat, consistent with either "no effect" or "already saturated").

**None of this blocks the verdict below** — it is recorded as an open, carried-forward question
for whoever next reads the full overlay text, exactly as TR-069 recorded it.
