# TR-024 — PF-08 F2: 360° Travel Choreography + Chase Camera

**Date:** 2026-07-18
**Scope:** [PF-08-flight-v3.md](../delivery-plan/PF-08-flight-v3.md) Phase F2 — the camera
detaches from its fixed forward frame during warp and chases the ship through changing angles;
free-look drag stays authoritative; arrival is a decelerating orbit-in, not a station snap.
**Verdict: OVERALL: READY TO PROCEED**

## What changed

1. **The ship owns the route.** During warp, `_shipWorld` travels the eased brachistochrone
   path (one ship-depth ahead of the old camera line); the camera is derived from it:
   `cam = shipWorld − (right·r + up·u + dir·back)` in a route-aligned `travelFrame`.
2. **Waypoint choreography** (`chaseOffsetAt`, smoothstep-interpolated): astern at launch →
   side quarter-view for departure → behind-above cruise → pulled wide for the flip → swung to
   the opposite flank and tightening for the brake — the decelerating orbit-in. Both curve ends
   sit exactly astern, so `cam(0) ≡ warp.from` and `cam(1) ≡ warp.to`: every post-warp
   invariant (arrival distance, parked framing, look direction) is preserved by construction.
3. **Chase look with look-ahead** — yaw/pitch damp (wrap-aware `dampAngle`,
   frame-rate-independent) toward a point `CHASE_LOOK_AHEAD` past the ship along the route —
   and are **never written while the pointer is down** (`_dragging` flag): free-look drag stays
   authoritative mid-flight; the chase re-engages gently on release (the plan's named UX risk).
4. **Spring-fed screen track** — the ship's world position is converted through the live view
   (`viewToNdc`) into NDC targets for the _existing_ station springs, so both warp boundaries
   hand off with mass instead of a snap, and the chase distance (2.3–3.9 units) breathes the
   apparent ship size through real perspective.
5. **Reduced motion:** fixed astern offset (`CHASE_OFFSET_REST`), snapped look — parity kept.
   `cosmos:warp` payload and phase names (`accel|flip|decel`) unchanged — WarpOverlay/HUD
   contracts untouched. Zero new runtime dependencies; no new GL state (context-restore safe).
