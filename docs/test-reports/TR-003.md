## Known Limitations / Caveats

- **Station sprite visual positioning could not be directly screenshot-confirmed in this session.** The preview browser tab runs backgrounded (`document.hidden === true`, same characteristic already documented in TR-001/TR-002), which throttles `requestAnimationFrame` and freezes the sprite-positioning tick loop after its first frame. Verified correctness a different way: read the engine's live projected coordinates for a station (`en.stations.find(...)`) and manually traced the exact `show` condition (`travel && px != null && !warp && !sectionOpen && !cardId && !vista`, plus the dodge-zone rectangle check) against the confirmed live state values - the logic evaluates to the expected result. This is evidence of correctness, not a substitute for seeing it animate in a real, foregrounded browser tab.
- **`Starfield.tsx`/`StarModal.tsx` are now unused but not deleted.** Confirmed via repo-wide search that nothing imports them anymore outside their own test files (which still pass). The handoff doc's own guidance is to delete them "once parity confirmed... via a normal commit, not a hard delete without review." Parity is confirmed as of this report, but deleting pre-existing, already-shipped files is exactly the class of action that required explicit confirmation earlier in this same engagement (a permission gate blocked an earlier attempt to delete shipped files on a general "continue" instruction) - so this was deliberately left for the user to confirm rather than actioned unilaterally.
- Moon Base **footer SVG swap** (the prototype's scroll-mode moon-landscape footer) was scoped out - see the delivery plan's Phase 4 notes. The "Moon Base" travel _station_ already has a full experience via `SectionOverlay`'s moonbase panel from Phase 3; the DOM `<footer>` swap is purely cosmetic and the existing Earth-surface footer + `MissionControl` island already serves the same functional purpose in scroll mode.
- No E2E coverage yet for the space scene - deferred to Phase 5 per the delivery plan.
