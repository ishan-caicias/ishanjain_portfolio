# TR-008 — HUDF.webp Asset Fix

**Date:** 2026-07-09
**Scope:** [docs/delivery-plan/PF-07-space-portfolio-webgl.md](../delivery-plan/PF-07-space-portfolio-webgl.md) — §6 follow-up

## Purpose

TR-007 found `public/assets/dso/HUDF.webp` (Hubble Ultra Deep Field) was a 0-byte file, confirmed
present (also empty) in the original prototype source, so unfixable by re-copying. User approved
fetching a real replacement.

## What Was Done

- Sourced the official 2004 HUDF release (`heic0611b`) from
  [esahubble.org](https://esahubble.org/images/heic0611b/) - confirmed via the image's own EXIF
  description ("This view of nearly 10,000 galaxies is called the Hubble Ultra Deep Field...")
  that it's the correct object, matching the catalog entry's description exactly.
- License: CC BY 4.0, credit "NASA, ESA, and S. Beckwith (STScI) and the HUDF Team" - confirmed
  via [esahubble.org/copyright](https://esahubble.org/copyright/) that personal portfolio use
  with attribution is permitted.
- Downloaded the "screensize JPEG" (1280×1280, 311KB), resized to 960×960 (matching sibling DSO
  images' convention, e.g. `M42.webp`) and converted to WebP (quality 82) via the `sharp` package
  already present in `node_modules`. Result: 98,248 bytes.
- No new Credits-section attribution added - the existing generic entry in `SectionOverlay.tsx`
  ("NASA / ESA · Hubble & JWST archives... public domain per NASA media guidelines") already
  covers this image, consistent with how all other DSO images are credited.
