# TR-018 — PF-07 Ship-v2 Phase 3: Thrusters and Arrival Presence

**Date:** 2026-07-17
**Scope:** [PF-07-spaceship-v2.md](../delivery-plan/PF-07-spaceship-v2.md) Phase 3 — realism audit fixes #2, #4, #5
**Verdict: OVERALL: READY TO PROCEED**

## What Was Delivered

1. **Layered exhaust (fix #2)** — `ship-dynamics.ts` gained the pure plume system
   (`PLUME_ENGINES`, `plumeFlareLength`, `plumeAlpha`, `buildPlumeVertices` with scratch-buffer
   reuse); the engine gained a dedicated plume program (crossed-quad cones per engine, vertex
   alpha nozzle→tip, additive blending, orange-tip → hot-core gradient) drawn between the ship
   and the nozzle-core points. Phase-driven: acceleration/deceleration burn = long + jittering,
   coast/flip = cut, parked = low idle breathing, in-flight idle = medium. Reduced motion =
   fixed lengths.
2. **Arrival presence (fix #4)** — the craft shader's rim color is now a uniform (`uRimCol`);
   the engine smooths `_rimK` toward warm beacon-gold while parked at a body, cool starlight in
   flight (`rimColorAt`). Plume response at parked comes via the same phase params.
3. **Quieter overlays during travel (fix #5)** — two parts:
   - **Verified pre-existing:** station sprites, hover tooltips, and cards are already fully
     suppressed during warp (`!s.warp` in the sprite tick) — recorded, no change needed.
   - **New:** the hero copy (`#ij-hero-copy`) dims to 0.12 opacity under `body.ij-warping`
     (toggled by SpaceScene from warp state), restoring on arrival — the one remaining
     fixed-screen element that dominated the P2 mid-warp frame. Reduced motion skips the fade.
4. **Latent P1 defect fixed in passing:** the nozzle-glow pass relied on the wireframe path's
   leftover attrib-array state — with the craft on, glow points were degenerate. Now enabled
   explicitly.
5. **Tests** — +5 unit (plume phase ordering, burn jitter vs reduced-motion invariance,
   brightness ordering, exact geometry with f32-aware assertions, rim interpolation/clamp);
   the warp E2E spec now also asserts `body.ij-warping` mid-flight, hero opacity < 0.5, and
   restoration after arrival.
